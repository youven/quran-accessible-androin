# وثيقة متطلبات القرآن الميسّر

## الهدف
تمكين كبار السن وذوي الإعاقة من قراءة القرآن والاستماع إليه وفهمه باستقلالية، على Android.
اللغة الأساسية العربية. لا يشترط حساب مستخدم للوظائف الأساسية.

## الشرط الأساسي للمصحف
مصحف المدينة برواية حفص، 604 صفحات. يحافظ العرض الأساسي على الرسم العثماني وتوزيع الكلمات والأسطر والصفحات.
النص مقبول فقط مع خطوط وبيانات تخطيط متطابقة ومراجعة؛ وإلا تستخدم صور الصفحات المطابقة.
لا يجوز تجميع صور الآيات والادعاء أنها صفحات مطابقة. وضع النص المكبر منفصل بوضوح عن وضع الصفحات.

## تجربة المستخدم
1. إعداد اختياري للقراءة الميسّرة ويمكن تخطيه.
2. الرئيسية: متابعة القراءة، السور، الاستماع، العلامات.
3. القارئ: الصفحة الحالية، السابق والتالي، التكبير، اختيار الآية.
4. تفاصيل الآية: تلاوة وتفسير وعلامة مرجعية.
5. التنزيلات: الحجم والتقدم والإلغاء وإعادة المحاولة وحذف التنزيل.
6. الإعدادات: حجم النص والتباين والتذكير والقارئ المفضل.

## نطاق الإصدار الأول المستهدف (منفذ جزئيًا)
- المصحف الكامل، فهارس السور والأجزاء والصفحات.
- آخر موضع وعلامات محلية.
- قراءة ميسرة بنص موثوق مطابق للآيات.
- TalkBack، ترتيب تركيز منطقي، عناصر تحكم مسماة.
- تلاوة آية أو سورة، تكرار، تشغيل بالخلفية، مؤقت توقف.
- تفسير مختصر باسم المصدر، مع وصول للنص الكامل المتاح.
- بحث محلي، تنزيل اختياري، واستمرار القراءة عند انقطاع الشبكة.

## إتاحة الاستخدام
- أزرار رئيسية بحد أدنى 64dp، ودون قص عند تكبير خط النظام إلى 200%.
- السابق والتالي أزرار ظاهرة؛ لا تعتمد الوظائف على السحب أو الضغط الطويل وحدهما.
- لا تعتمد الحالات على اللون أو الصوت وحدهما.
- النص القرآني متاح دلاليًا آية آية؛ صورة الصفحة لا توصف كنص واحد طويل.
- لا يبدأ الصوت تلقائيًا؛ يمنع تداخل شرح الواجهة مع التلاوة.
- ألوان عالية التباين مع فحص فعلي للتباين.
- فيديوهات التعليم تتطلب نصوصًا مصاحبة. لغة الإشارة تحتاج محتوى متخصصًا ومراجعًا.

## المراحل التالية
- الورد والختمة والتذكير الاختياري، الحفظ والمراجعة، تفاسير وترجمات إضافية.
- الأوامر الصوتية ومحتوى التجويد والشروح الصوتية ولغة الإشارة.
- لا يدخل تفسير مولد آليًا أو تصحيح تلاوة آلي ضمن الإصدار الأول.

## قبول الإصدار
- مراجعة الصفحات كلها مقابل النسخة المرجعية، مع فحص خاص لصفحات 1 و2 وانتقالات السور وآخر صفحة.
- تطابق الآية المختارة والصوت والتفسير في جميع طرق العرض.
- اختبار التكبير والدوران وإعادة فتح التطبيق وانقطاع التنزيل.
- اختبار TalkBack والتنقل بالمفاتيح/وسائل الإدخال المساعدة مع مستخدمين فعليين.
- نجاح build وlint، وعدم قص الأزرار مع تكبير النص.
- لا يُعتمد الإصدار قبل مراجعة صحة المحتوى وحقوق توزيعه.
