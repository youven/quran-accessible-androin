# القرآن الميسّر — Android

قارئ قرآن عربي يراعي كبار السن ومستخدمي قارئ الشاشة.

## الإصدار 0.3.3: إصلاح تحميل الصفحات الناقصة وفحص الخطوط

يعالج هذا الإصدار سببين إضافيين لفشل الصفحات: المسافة داخل رمز الكلمة عند علامة الحزب (مثل صفحتي ٥ و١٠٠)، واستجابة بيانات ناقصة للصفحة ٦٠٠ (٢١ آية بدل ٢٥). يفحص التطبيق رموز الخط مباشرةً من ملفه، ويستكمل الصفحة الناقصة بطلب بيانات السور من المصدر نفسه ثم يتحقق من العدد والأسطر قبل عرضها. لا توجد معالجة خاصة برقم صفحة بعينها، ولا يُسمح بعرض صفحة ناقصة.

تُعاد محاولة تنزيل ملفات الخطوط المخزنة التالفة تلقائيًا. تُحفظ بيانات الصفحة بعد التحقق الكامل منها، مع تجاوز بيانات التخزين المؤقت القديمة. راجع [نتائج الاختبار وحدود التحقق](docs/TESTING.md).

- نصوص Quran.com مع `code_v2` وخط QCF V2 الخاص بكل صفحة، وبيانات `page_number` و`line_number` للمصحف المدني 1421هـ، رواية حفص، 604 صفحات.
- رسم الكلمات الأصلية وأرقام الآيات كحروف خطية قابلة للتكبير، دون صور صفحات أو إعادة توزيع الكلمات تلقائيًا.
- تكبير بالإصبعين حول نقطة اللمس، سحب، ونقر مزدوج للتكبير/العودة. أدوات تكبير وتصغير دون إيماءات.
- الوضع الرأسي يلائم الصفحة؛ الوضع الأفقي يلائم عرض الشاشة مع تمرير رأسي.
- وضع «النص الميسّر وقارئ الشاشة» يعرض النص العربي الحقيقي بحجم قابل للتعديل. هذا الوضع يعيد تدفق النص عمدًا ولا يحاكي صفحة المصحف.
- إعادة محاولة تلقائية للطلبات البطيئة، واتباع تحويلات الخادم، وحفظ نص الصفحة وخطها في ذاكرة التخزين المؤقت بعد نجاح التحميل.
- متابعة القراءة، علامات محفوظة، انتقال إلى أي صفحة بأرقام عربية أو إنجليزية.

**حدود المطابقة:** ترتيب الكلمات والأسطر ورسم الآيات مصدرها بيانات المصحف وخطوطه. عناوين السور بخط مخصص من المصدر نفسه؛ الزخارف والإطار الطباعي ليست نسخة مطابقة. لم تُراجع الصفحات الـ604 بصريًا على جهاز، لذلك هذه نسخة تطوير وليست إصدارًا مُراجعًا للنشر.

## المصدر والاتصال

المصدر العام المستخدم: `https://api.quran.com/api/v4`، دون مفتاح في الطلبات التي تم التحقق منها. الخطوط من Quran Foundation. لا توجد رسوم API أو أسرار مضمّنة في التطبيق، ولا ضمان تعاقدي لتوافر الواجهة العامة. واجهة Quran Foundation الحديثة تحتاج اعتمادًا منفصلًا وخادمًا لحماية الأسرار عند الانتقال إليها.

يلزم الإنترنت لتحميل الصفحات. تخزين مؤقت محدود في ذاكرة الجلسة، دون تنزيل مكتبة خطوط أو وعد بالقراءة الدائمة دون اتصال. راجع [المصادر والحقوق](docs/CONTENT.md).

## البناء

Android Studio، JDK 17، Android SDK 35:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

ملف APK: `app/build/outputs/apk/debug/app-debug.apk`. مسار GitHub Actions نفسه ينشئ APK عند توافر مشغّل للحساب.

راجع [الاختبار](docs/TESTING.md) و[البنية](docs/ARCHITECTURE.md). التلاوة والتفسير والبحث أهداف لاحقة، وليست وظائف منفذة في هذه النسخة.
