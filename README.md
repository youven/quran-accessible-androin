# القرآن الميسّر — Android

تطبيق قرآن لكبار السن وذوي الإعاقة، مع الالتزام بالرسم وتخطيط صفحات مصحف المدينة برواية حفص (604 صفحات).

## الحالة الحالية
هيكل أولي بـ Kotlin وJetpack Compose، وشاشة عربية لإعداد وضع القراءة الميسّر. ليست نسخة مصحف مكتملة: لم تُدمج صفحات المصحف أو التلاوات أو التفسير بعد، ولم تُختبر مطابقة الصفحات.

## التشغيل
- JDK 17، Android SDK 35، وGradle 8.11.1.
- افتح المجلد في Android Studio.
- هذا الهيكل لا يحتوي Gradle Wrapper بعد. بعد تثبيت Gradle 8.11.1 شغّل:
  `gradle wrapper --gradle-version 8.11.1`
- ثم: `./gradlew :app:assembleDebug :app:lintDebug` (على Windows استخدم gradlew.bat).
- إعدادات SDK الحالية للتطوير؛ تُراجع متطلبات Google Play قبل النشر.
- لم يُجرَ بناء APK في بيئة الإنشاء؛ لا يُعد هذا الهيكل إصدارًا جاهزًا للنشر.
