# القرآن الميسّر — Android

تطبيق قرآن لكبار السن وذوي الإعاقة. يعتمد قارئ المصحف على صور صفحات مصحف المدينة برواية حفص، مع الحفاظ على الرسم والتنسيق الأصليين.

## المنفذ في 0.2.0
- واجهة عربية بـ Kotlin وJetpack Compose، بألوان هادئة وأزرار تنقل كبيرة.
- قارئ صفحات 1–604 من مصدر جامعة الملك سعود، مع التحميل عند الطلب.
- الصفحة السابقة والتالية، والانتقال برقم الصفحة بالأرقام العربية أو الفارسية أو الإنجليزية.
- تكبير حتى 300%، تمرير الصورة وأزرار تحريك بديلة للسحب، والعودة لحجم الصفحة الكامل.
- علامات مرجعية وحفظ آخر صفحة فُتحت بنجاح.
- حفظ الصفحات المفتوحة في مساحة التطبيق للقراءة دون اتصال. لا يُنزّل المصحف كاملًا تلقائيًا.
- رسائل تحميل وفشل وإعادة المحاولة، والتحقق من نوع وحجم الصور قبل حفظها.

## التشغيل
1. افتح المجلد في Android Studio مع JDK 17.
2. ثبّت Android SDK 35 وBuild Tools 35.0.0.
3. نفّذ `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`.
   على Windows استخدم `gradlew.bat`.
4. الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

Gradle Wrapper 8.11.1 مرفق مع تحقق SHA-256 للتوزيعة.
[فحوص البناء ونسخ APK التجريبية](https://github.com/youven/quran-accessible-androin/actions)
تشغيل GitHub Actions الناجح يوفّر الملف `quran-accessible-debug` ضمن Artifacts لمدة 7 أيام. وجود الملف في المستودع لا يعني نجاح آخر فحص؛ تحقق من نتيجة التشغيل.

## حدود النسخة الحالية
- الصور متاحة عبر HTTPS من مشروع جامعة الملك سعود، وليست API رسمية موثقة بضمان توافر.
- جرى تنزيل وفحص عينات الصفحات 1 و2 و604 بصريًا. لم تجر مراجعة الصفحات الـ604 كاملة.
- دقة العينات 622×917؛ التكبير يحافظ على الصورة لكنه لا يضيف تفاصيل جديدة.
- TalkBack يستطيع تشغيل عناصر الواجهة، لكن نص الآيات الدلالي والتلاوة والتفسير وفهارس السور لم تدمج بعد. لا تعد هذه النسخة تجربة مكتملة للمكفوفين.
- الصور لا تتضمن إحداثيات الآيات في التطبيق بعد، لذلك لا يوجد تحديد آية بالضغط عليها.
- صفحات الجهاز تبقى حتى حذف بيانات التطبيق أو إزالته؛ إدارة تنزيل المصحف كاملًا مرحلة لاحقة.
- لا توجد اختبارات فعلية على جهاز أو محاكي حتى الآن. هذه نسخة تطوير وليست إصدار Google Play.
- مراجعة حقوق إعادة استخدام المحتوى، وصحة المصحف كاملًا، ومتطلبات Google Play بوابات لازمة قبل النشر العام.
